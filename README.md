# FlowPilot AI

Ferramenta para automatizar follow-ups comerciais usando IA.

O projeto surgiu da necessidade de reduzir perda de leads por falta de acompanhamento. A proposta é integrar canais como Gmail e WhatsApp, acompanhar interações e automatizar parte do processo comercial.

## Stack

* Next.js
* TypeScript
* Supabase
* PostgreSQL
* Redis
* BullMQ
* OpenAI

## Instalação

```bash
pnpm install
```

## Rodando o projeto

```bash
pnpm dev
```
